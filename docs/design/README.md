# Loop Rebirth · Game design (เฟส 0)

Loop Rebirth คือ roguelite ที่ต่อยอดจาก Loop Hero: ฮีโร่เดินวน loop ที่เปลี่ยนทุก run, ครบรอบได้การ์ดมาวางสร้างโลก,
บ้านที่วางรวมกันเป็นเมืองที่โตไปพร้อม run และทุกอย่างจบในตานั้น ยกเว้น Rebirth point ที่ใช้ปลดล็อก utility และการ์ดใหม่

เอกสารในโฟลเดอร์นี้คือ spec ของ MVP ทุกตัวเลขเป็นค่าเริ่มต้นสำหรับ prototype และจะจูนหลังเล่นจริง

## คำศัพท์

| คำ | ความหมาย | รีเซ็ตเมื่อจบ run |
| --- | --- | --- |
| stat point | ได้ 3 แต้มทุก level up ใช้อัพ STR, AGI, INT | รีเซ็ต |
| การ์ด tile | การ์ดที่วางบนแผนที่: ภูมิประเทศ, encounter, อาคาร, พิเศษ | รีเซ็ต |
| skill card | การ์ด skill ใส่ช่อง skill ของฮีโร่ วางใบเดียวกัน level เดียวกันทับเพื่อขึ้น level | รีเซ็ต |
| merge | วางการ์ดชื่อเดียวกัน level เดียวกันทับ แล้วขึ้น 1 level สูงสุด L3 | |
| Rebirth point (RP) | ได้จากเป้าหมาย run และการฆ่าบอส | ติดตัวข้าม run |
| Rebirth tree | ที่ใช้ RP ปลดล็อกการ์ด, skill card และอัพ utility | ติดตัวข้าม run |

## สิ่งที่ตัดสินแล้ว (26 ต.ค. 2026)

1. บอสมาที่รอบ 10 ตายตัวใน MVP
2. ครบรอบเลือกการ์ด 1 จาก 3, การต่อสู้ให้ XP และของ
3. เมืองขึ้นขั้นตามจำนวนอาคาร แต่ละขั้นเลือก perk
4. skill ทำงานเองตาม mana
5. ทุกการเลือกเป็น notification ข้างจอ กดเมื่อไรก็ได้ หรือตั้งให้เด้งตอนครบรอบ
6. ไม่มีระบบถอยและไม่มีสิ่งปลูกสร้างนอกเกม run จบเมื่อชนะบอสหรือตาย ได้ Rebirth point จากบอสและเป้าหมาย
7. MVP ใช้การ์ดที่ปลดล็อกทั้งหมด ยังไม่มีการเลือก deck
8. เป้าหมายระยะยาวตัดสินทีหลัง
9. engine: Godot 4
10. stat point รีเซ็ตทุก run, skill เป็นการ์ด merge 2 ใบขึ้น level, แต้มหลังจบเกมชื่อ Rebirth point

## ยังต้องเคาะ

- มีศัตรูป่าหรือไม่ ([01](01-run.md))
- เลือกการ์ด 2 ครั้งต่อรอบพอไหม ([02](02-cards.md))
- RP จากเป้าหมายยังได้ไหมถ้าตายทีหลัง และช่อง skill ที่ 3 ถือเป็น utility ไหม ([06](06-meta.md))
- จูน INT และโล่มานาตามปัญหาที่รู้แล้วใน [04](04-hero-combat.md)
- platform และขนาดทีม
