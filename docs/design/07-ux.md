# 07 · หน้าจอ notification และการตั้งค่าภาพใน Godot

ทุกอย่างที่ต้องเลือก (stat point, การ์ดรอบ, skill card, ของ, perk เมือง, event) ขึ้นเป็น notification ข้างจอ
ผู้เล่นกดเมื่อไรก็ได้ หรือตั้งให้เด้งเองตอนครบรอบ เกมไม่บังคับหยุดเพื่อให้เลือก

## Notification

| ชนิด | มาจาก | ค้างได้ |
| --- | --- | --- |
| stat point | level up | ไม่จำกัด |
| skill card | level up, elite, event | ไม่จำกัด |
| การ์ดรอบ | ครบรอบ (2 ครั้ง) | ไม่จำกัด |
| ของ | ศัตรูดรอป | 5 ชิ้น (เกินแล้วชิ้นเก่าสุดเป็น XP) |
| perk เมือง | เมืองขึ้นขั้น | ไม่จำกัด |
| event | เดินผ่านจุด "?" | ไม่จำกัด |
| เป้าหมายสำเร็จ | ทำเป้าหมาย run ครบ | แจ้งเฉยๆ หายเองใน 5 วินาที |

- กด notification แล้วเปิดแผงเลือก ระหว่างแผงเปิด เกมหยุด (ค่าเริ่มต้น ปิดได้ในตั้งค่า)
- ตั้งค่า "เปิดเองตอนครบรอบ": พอครบรอบ เกมหยุดและเปิดตัวเลือกที่ค้างทีละอัน
- notification เรียงตามเวลาที่เกิด และมีไอคอนบอกชนิด

## หน้าจอ

- ความละเอียดภายใน 480 × 270 (16:9) ขยายแบบจำนวนเต็ม ×4 เป็น 1920 × 1080
- แถบบน 16 px: HP, mana, XP, รอบ, Rebirth point ที่ได้ใน run นี้, ปุ่มความเร็ว
- แผนที่ 352 × 208 px (22 × 13 ช่อง ช่องละ 16 px) มุมซ้าย
- แผง notification ด้านขวา 128 px
- แถบมือการ์ดด้านล่าง 46 px (การ์ด tile และ skill card อยู่ในมือเดียวกัน) ช่อง skill ของฮีโร่อยู่ที่แผงขวา
- ความเร็ว: หยุด (Space), x1, x2, x4

## การวางการ์ด

- ลากการ์ดจากมือ ช่องที่วางได้ไฮไลต์
- ก่อนปล่อย ถ้าจะเกิด merge หรือ combo ให้แสดงไอคอนและผลลัพธ์ล่วงหน้า
- combo ลบ (หมู่บ้านผีสิง) แสดงเป็นสีเตือน

## ตั้งค่า pixel art ใน Godot 4

```
display/window/size/viewport_width           = 480
display/window/size/viewport_height          = 270
display/window/stretch/mode                   = viewport
display/window/stretch/scale_mode             = integer
rendering/textures/canvas_textures/default_texture_filter = Nearest
```

art direction (โทนสดใส, top-down 3/4, palette Endesga 32, ตัวเลือกพื้นหลัง) อยู่ในเอกสารวิเคราะห์ส่วน Art direction
