# 02 · การ์ด การวาง combo และ merge

ครบรอบแล้วเลือกการ์ด 1 จาก 3 สองครั้ง การ์ดวางบนช่องทางหรือข้างทาง
วางการ์ดชื่อเดียวกันและ level เดียวกันทับเพื่อขึ้น level (สูงสุด 3) และการ์ดบางคู่ที่วางติดกันเกิด combo
ข้อมูลการ์ดทั้งหมดอยู่ใน [data/cards.csv](../../data/cards.csv)

## ได้การ์ดอย่างไร

- **ครบรอบ** เลือก 1 จาก 3 จำนวน 2 ครั้ง แต่ละครั้งเป็น notification แยก ([07-ux](07-ux.md))
- **กติกาช่วย merge** ใน 3 ใบที่เสนอ อย่างน้อย 1 ใบต้องเป็นการ์ดที่มีบนแผนที่หรือในมือแล้ว ถ้ามี
- **มือ** ถือได้ 10 ใบ รวม skill card (Rebirth tree เพิ่มได้อีก 3 ใบ) ถ้าเต็ม ใบเก่าสุดถูกไล่ออกและให้ XP 5
- **pool** MVP สุ่มเท่ากันจากการ์ดที่ปลดล็อกแล้วทั้งหมด การเลือก deck ก่อน run มาทีหลัง
- การต่อสู้ไม่ให้การ์ด tile การต่อสู้ให้ XP และของ
- skill card ใช้ระบบการ์ดและการ merge แบบเดียวกัน แต่ได้จาก level up และวางทับที่ช่อง skill ของฮีโร่ ดู [04-hero-combat](04-hero-combat.md)

## Merge

- วางการ์ดชื่อเดียวกันและ level เดียวกันทับช่องที่มีการ์ดนั้น แล้วช่องนั้นขึ้น 1 level สูงสุด L3
- merge ได้เฉพาะบนแผนที่ ในมือไม่ได้ (ตามไอเดีย "วางทับ")
- merge encounter เพิ่มทั้งจำนวนศัตรูและรางวัล
- L3 ต้องใช้การ์ด L1 รวม 4 ใบ

## Tile combo (MVP 4 แบบ)

"ติดกัน" หมายถึง 8 ทิศ combo ทำงานทันทีที่วางครบคู่ และหยุดเมื่อช่องใดช่องหนึ่งถูกรื้อ

| combo | เงื่อนไข | ผล |
| --- | --- | --- |
| น้ำพุร้อน | หิน ติดกับ บ่อน้ำ | บ่อน้ำนั้นฟื้น 5% max HP เมื่อเดินผ่านช่องทางที่ติดกัน |
| สวน | ทุ่งดอกไม้ ติดกับ บ้าน | บ้านนั้นนับเพิ่มอีก 1 หลังสำหรับเมือง |
| ป่าลึก | ป่า ติดกับ ถ้ำหมาป่า | ถ้ำนั้นมีหมาป่าเพิ่ม 1 ตัว แต่ XP ×1.5 |
| หมู่บ้านผีสิง | สุสาน ติดกับ บ้าน | บ้านนั้นไม่ฟื้น HP และไม่นับเป็นอาคาร (combo ลบ ให้ผู้เล่นระวังการวาง) |

## Set combo (หลัง MVP)

นิยามที่เสนอ: มีการ์ดครบชุดตามเงื่อนไขที่ไหนก็ได้บนแผนที่ ไม่ต้องติดกัน
ตัวอย่าง: ภูมิประเทศครบ 4 ชนิด ได้ "สมดุลธรรมชาติ" ผลภูมิประเทศทั้งหมด +20%

## ยังต้องเคาะ

- เลือกการ์ด 2 ครั้งต่อรอบพอไหม (จูนในเฟส 2)
- การ์ดที่ถูกไล่จากมือควรได้ XP หรืออย่างอื่น
