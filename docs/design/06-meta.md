# 06 · Rebirth point และ Rebirth tree

แต้มที่ติดตัวข้าม run มีอย่างเดียวคือ **Rebirth point (RP)** ได้จากเป้าหมาย run และการฆ่าบอส แล้วใช้ใน **Rebirth tree** หลังจบ run
Rebirth tree มีแค่ utility และการปลดล็อกการ์ด ไม่มีการเพิ่ม stat และไม่มีสิ่งปลูกสร้างนอก run
ชื่อ Rebirth tree ใช้แยกจาก skill card ในตา ([04-hero-combat](04-hero-combat.md)) ไม่ให้สับสน

## ได้ Rebirth point อย่างไร

| แหล่ง | RP | หมายเหตุ |
| --- | --- | --- |
| เป้าหมาย run (3 ข้อต่อ run) | 1 ต่อข้อ | ทำครบเมื่อไรได้ทันทีและเก็บไว้แม้สุดท้ายจะตาย (สมมติฐาน รอ Phupha ยืนยัน) |
| ฆ่าบอส | 2 | |

- RP ที่ได้ระหว่าง run แสดงเป็นตัวนับบนจอ และสรุปบนหน้าจบ run
- ใช้ RP ได้บนหน้า Rebirth tree หลังจบ run เท่านั้น ระหว่าง run ใช้ไม่ได้ และไม่มีร้านหรือการสร้างนอกเกม
- สูงสุดต่อ run 5 RP (หรือมากกว่าถ้าอัพ "เป้าหมายเพิ่ม")

เป้าหมาย run สุ่มจาก [data/run_goals.csv](../../data/run_goals.csv) เช่น ถึง level 7, สร้างหมู่บ้าน, merge การ์ดใบใดก็ได้ถึง L3

## Rebirth tree

ข้อมูลเต็มอยู่ใน [data/rebirth_tree.csv](../../data/rebirth_tree.csv) node ที่อัพได้หลายขั้นจ่ายแยกทีละขั้น

| node | สาย | ผลต่อขั้น | ขั้น | ราคาต่อขั้น (RP) | ต้องมีก่อน |
| --- | --- | --- | --- | --- | --- |
| มือใหญ่ขึ้น | utility | ถือการ์ดได้ +1 ใบ | 3 | 1 / 2 / 3 | |
| ตาแหลม | utility | รางวัลรอบเสนอ 4 ใบแทน 3 | 1 | 2 | มือใหญ่ขึ้น 1 |
| สุ่มใหม่ | utility | สุ่มการ์ดที่เสนอใหม่ได้ +1 ครั้งต่อรอบ | 2 | 2 / 3 | ตาแหลม |
| ออกตัวไว | utility | เริ่ม run ด้วยการเลือกการ์ดเพิ่ม +1 ครั้ง | 2 | 1 / 2 | |
| แผนที่ร่าง | utility | ดูรูป loop ก่อนเริ่มและสุ่มใหม่ได้ +1 ครั้ง | 2 | 1 / 2 | |
| เป้าหมายเพิ่ม | utility | เป้าหมาย run +1 ข้อ | 2 | 2 / 3 | |
| ช่อง skill ที่ 3 | utility | ฮีโร่มีช่อง skill 3 ช่อง | 1 | 4 | |
| ค่ายโจร | ปลดล็อกการ์ด | การ์ด encounter ค่ายโจรเข้า pool | 1 | 1 | |
| ศาลเจ้า | ปลดล็อกการ์ด | การ์ดศาลเจ้าเข้า pool | 1 | 1 | |
| โรงตีเหล็ก | ปลดล็อกการ์ด | การ์ดโรงตีเหล็กเข้า pool | 1 | 1 | |
| รื้อถอน | ปลดล็อกการ์ด | การ์ดรื้อถอนเข้า pool | 1 | 2 | |
| ฟื้นฟู | ปลดล็อก skill | skill card ฟื้นฟูเข้า pool | 1 | 1 | |
| เร่งความเร็ว | ปลดล็อก skill | skill card เร่งความเร็วเข้า pool | 1 | 1 | |

ราคารวมทั้ง tree 36 RP ถ้าได้เฉลี่ย 2 ถึง 4 RP ต่อ run จะปลดครบในราว 10 ถึง 15 run

## ยังต้องเคาะ

- RP จากเป้าหมายที่ทำครบแล้วยังได้ไหมถ้าตายทีหลัง (ตอนนี้สมมติว่าได้)
- ช่อง skill ที่ 3 นับเป็น utility หรือเป็นการเพิ่มพลังที่ควรเลี่ยง
