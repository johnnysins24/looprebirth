# 01 · โครงสร้าง run

run หนึ่งมี 10 รอบ ครบรอบที่ 10 เจอบอส และจบเมื่อชนะบอสหรือตายเท่านั้น ไม่มีการถอย
เป้าหมายความยาวคือ 12 ถึง 18 นาทีที่ความเร็ว x1 ทุกอย่างในตา (level, stat point, skill card, ของ, การ์ด, เมือง) รีเซ็ตเมื่อ run จบ มีแค่ Rebirth point ที่ติดตัวข้าม run

## ลำดับของ run

1. **ก่อนเริ่ม** สุ่ม loop จาก seed, สุ่มเป้าหมาย run 3 ข้อ ([06-meta](06-meta.md)), ฮีโร่ L1, มือเริ่มต้น 3 ใบ (ภูมิประเทศ 1, encounter 1, บ้าน 1)
2. **เดิน** ฮีโร่ออกจากช่องค่ายแล้วเดินตามเข็มนาฬิกา หยุดเดินเฉพาะตอนสู้
3. **สู้** เดินเข้าช่องทางที่มีศัตรูแล้วเกิด auto battle ([04-hero-combat](04-hero-combat.md))
4. **ครบรอบ** กลับถึงค่าย: ฟื้น 15% max HP, ได้รางวัลรอบ (เลือกการ์ด 2 ครั้ง), encounter ทุกช่องเกิดศัตรูใหม่, ศัตรูป่าเกิดใหม่, ระดับศัตรูเพิ่ม 1
5. **บอส** เมื่อครบรอบที่ 10 บอสปรากฏที่ค่ายและสู้ทันที
6. **จบ** ชนะบอสหรือ HP เหลือ 0 แล้วสรุปผล รับ Rebirth point ที่สะสมใน run แล้วกลับหน้า Rebirth tree ([06-meta](06-meta.md))

## ตัวเลขหลัก

| ค่า | เริ่มต้น | หมายเหตุ |
| --- | --- | --- |
| ความยาว loop | 28 ถึง 36 ช่องทาง | สุ่มตาม seed |
| ความเร็วเดิน | 1 ช่องต่อ 0.8 วินาที ที่ x1 | ไม่นับเวลาสู้ |
| รอบที่บอสมา | 10 | MVP ตายตัว แบบเกจภัยค่อยลองทีหลัง |
| ฟื้นที่ค่าย | 15% max HP | ทุกครั้งที่ครบรอบ |
| ศัตรูป่า | 2 + floor(รอบ / 3) กลุ่มสไลม์ ต่อรอบ | เกิดบนช่องทางว่างแบบสุ่ม (ข้อเสนอ) |
| ระดับศัตรู | เท่ากับเลขรอบ | สูตรการโตอยู่ใน 04 |
| ความเร็วเกม | หยุด, x1, x2, x4 | |

ศัตรูป่ามีไว้ให้ฮีโร่ได้ XP พื้นฐานแม้ผู้เล่นวาง encounter น้อย ถ้าเล่นแล้วรู้สึกว่าแย่งบทบาทการ์ด encounter ให้ตัดออก

## ตัวสร้าง loop

- กระดาน 22 × 13 ช่อง (ช่องละ 16 px รวม 352 × 208 px)
- loop ต้องปิด ไม่มีทางแยก และช่องทางที่ไม่ได้ต่อกันตามลำดับห้ามติดกัน 4 ทิศ (กันทางกำกวม)
- ทุกช่องทางต้องมีช่องข้างทางว่างอย่างน้อย 1 ช่อง และรวมทั้งแผนที่มีช่องข้างทางว่างอย่างน้อย 40 ช่อง
- ค่ายอยู่บน loop และห่างขอบกระดานอย่างน้อย 2 ช่อง
- วิธีที่เสนอ: เริ่มจากสี่เหลี่ยม 12 × 6 กลางกระดาน แล้วสุ่ม "ดัน" ช่วงทางตรงออกหรือเข้า 1 ถึง 2 ช่อง 30 ถึง 60 ครั้ง ถ้าผิดกฎให้ย้อนครั้งนั้น
- เก็บ seed ไว้เพื่อเล่นซ้ำและใช้ทดสอบ balance
