# Art contract (ไฟล์ภาพที่เกมโหลด)

เกมหาภาพจาก `res://assets/art/<category>/<id>.png` ถ้ามีไฟล์ก็ใช้ไฟล์ ถ้าไม่มีก็วาด placeholder จากโค้ด (`src/autoload/art.gd`) ในขนาดและเลย์เอาต์เดียวกัน
ดังนั้นใส่ภาพจริงทีละไฟล์ได้ ไม่ต้องแก้โค้ด และไม่ต้องรอให้ครบ placeholder ที่ยังไม่ถูกแทนจะเป็นสีที่เห็นว่าเป็นของชั่วคราว

- palette Endesga 32 (ค่าสีอยู่ใน `Art.C`) พื้นหลังหน้าจอสลับได้ด้วยปุ่ม B ภาพต้องอ่านออกบนทั้ง 4 พื้น (ทะเล / ทุ่งหญ้า / กระดาษเก่า / น้ำเงินเข้ม)
- PNG ไม่มี anti-alias พื้นหลังโปร่งใส ช่องไม่มีเงาโปร่งแสงเกินจำเป็น (placeholder ใช้เงาโปร่งแสงใต้ตัวละครเล็กน้อย)
- import ของ Godot: filter = Nearest, mipmaps = off (ตั้งเป็น default ของ project แล้ว)
- ขนาดช่องบนแผนที่ 16x16 px บนกริด 480x270 (แผนที่ 22x13 ช่อง)

## tiles

| ไฟล์ | ขนาด | เลย์เอาต์ |
| --- | --- | --- |
| `tiles/land.png` | 64x64 | atlas dual-grid 4x4 tile ขนาด 16x16 index = บิตมุม 1 บนซ้าย, 2 บนขวา, 4 ล่างซ้าย, 8 ล่างขวา (บิตเปิด = มุมนั้นเป็นแผ่นดิน) วาง tile ที่จุดตัดของช่อง ไม่ใช่กลางช่อง ดังนั้น tile ทับกึ่งกลางระหว่าง 4 ช่อง index = col + row*4 |
| `tiles/road.png` | 256x16 | 16 เฟรม 16x16 เรียงแนวนอน เฟรม = mask ทิศที่ถนนไปต่อ: N=1, E=2, S=4, W=8 (เช่น เฟรม 5 = เหนือ+ใต้ = ถนนตรงแนวตั้ง) |
| `tiles/camp.png` | 16x16 | ค่ายเริ่มต้น/จุดที่บอสออกมา |

## map (วัตถุบนแผนที่ = หน้าการ์ดด้วย)

ไฟล์ละ 48x24 = 3 เฟรม 16x24 สำหรับการ์ดเลเวล 1, 2, 3 (เลเวลสูงดูหนาแน่น/ใหญ่ขึ้น)
ครึ่งล่าง 16 px คือช่องที่วัตถุยืน จุดยึดคือกึ่งกลางล่าง 8 px บนเป็นส่วนที่ยื่นขึ้นไปได้ (ต้นไม้, หลังคา)
การ์ดในมือใช้ภาพชุดเดียวกัน กรอบการ์ด 32x44 วาดด้วยโค้ด

ids: `rock`, `grove`, `meadow`, `spring`, `slime_nest`, `wolf_den`, `graveyard`, `bandit_camp`, `house`, `smithy`, `shrine`, `clear`
(`clear` ไม่เคยถูกวางลงแผนที่ ใช้เป็นภาพบนหน้าการ์ดอย่างเดียว)

## units

| ไฟล์ | ขนาด | เลย์เอาต์ |
| --- | --- | --- |
| `units/hero.png` | 32x64 | 4 แถว x 2 เฟรม 16x16 แถว: 0 หันลง, 1 หันซ้าย, 2 หันขวา, 3 หันขึ้น เฟรม 0-1 = วงจรเดิน (สลับ ~6 ครั้ง/วินาที) ใช้แถว 2 (ขวา) ตอนต่อสู้ |
| `units/slime.png`, `wolf.png`, `skeleton.png`, `bandit.png` | 32x16 | 1 แถว x 2 เฟรม ท่ายืน/ขยับ (สลับ ~2.5-3 ครั้ง/วินาที) |
| `units/boss_warden.png` | 64x32 | 2 เฟรม 32x32 (ใหญ่ 2x2 ช่อง) จุดยึดกึ่งกลางล่าง |

ตัวละครยึดกึ่งกลางล่างของช่อง (เท้าอยู่ล่างสุดของเฟรม)

## icons (16x16)

`icons/stat_str.png`, `stat_agi.png`, `stat_int.png`; `icons/skill_fireball.png`, `skill_cleave.png`, `skill_heal.png`, `skill_haste.png`, `skill_mana_shield.png`
(ไอคอนอื่นของ UI เช่นกรอบ ปุ่ม ยังวาดด้วยโค้ดทั้งหมด จะย้ายมาเป็นภาพเมื่อ art direction ของ UI นิ่ง)

## fonts

`assets/art/fonts/Sarabun-Regular.ttf` และ `Sarabun-Bold.ttf` (OFL, ตัวอ่านภาษาไทยที่ขนาด 6-9 px) ถ้าจะเปลี่ยนฟอนต์ต้องทดสอบที่ 6 px ก่อน

## ตรวจว่าภาพเข้ากับเกม

```
xvfb-run -a godot --path . --rendering-driver opengl3 -- --seed 7 --fast 90 --bg 1 --shot /tmp/a.png
```

`--bg 0..3` เลือกพื้นหลัง, `--hold 0` ถือการ์ดช่องแรกเพื่อดูไฮไลต์ช่องที่วางได้ ดู [README](README.md) สำหรับอาร์กิวเมนต์อื่น
